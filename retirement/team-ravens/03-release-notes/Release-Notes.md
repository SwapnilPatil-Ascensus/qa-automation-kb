### Release Note Standards

- Create one page per production deployment.
- Include the TrakIT number, implementation date, deployed stories, modules, owners, validation results, rollback strategy, and final outcome.
- Keep draft pages unpublished until the deployment scope and TrakIT information are confirmed.
