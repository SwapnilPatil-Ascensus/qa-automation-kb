| **ℹ️ Onboarding Issue Tracking Status Definitions** |
| --- |
|  |

| **New** | Ticket has not been reviewed |
| --- | --- |
| **Approved** | Ticket is approved and awaiting production deployment |
| **Ready For Testing** | Ticket is awaiting team/business testing |
| **Done** | Ticket is in production and completed |
| **In Review** | Ticket is in review to decide if we need a story |
| **Awaiting Prioritization** | Ticket has a story but is not assigned to a scrum team sprint |
| **Committed** | Ticket has a story and is in a scrum team sprint |
| **Blocked** | Ticket is blocked |
| **Duplicate** | Ticket is duplicate |
| **Not an Issue** | Ticket is not an issue |
