## Configuration

### Document Type mapping

- We need to be able to identify certain documents received from PAS based on their filename so we can properly index them into Cliff.  This is also necessary to run validation against the PAS package to ensure that we've received everything that we're expecting from PAS.
- Configuration can be found in Onboarding.Messaging.Api: “DocumentMapping:DocumentTypes”
- DocumentTypes configured per document filename

### Expected documents for PAS for each product

- Configuration can be found in Onboarding.Messaging.Api: “PasExpectedDocuments:Requirements”
- Requirements configured per product specifications.
- [PAS Package Validation (Group 2)](https://ascensus0.sharepoint.com/sites/TeamWhiteCF/SitePages/MTP-PAS-Package-Validation-(Group-2%29-341947634.aspx)

## Troubleshooting Errors in InitializePlanDocumentsCmdState command

### In-progress States

#### GeneratePASDocumentsSubmitted

During this state, Plan Setup API is making the request to PAS to begin generating the plan document package

#### VerifyingDocumentsStatus

During this state, polling requests are being made from Plan Setup API to PAS to check whether the generation of the document package has been completed

#### ProcessPASDocumentsDataSubmitted

During this state, Onboarding makes a pass-through request to Plan Setup API (to PAS) to generate the plan document package

After the package has been retrieved, validation is applied to check that the package contains every document we expected per the product configuration

- If one or more expected documents are missing, the entire package is rejected and the plan moves on to manual document scenario
  - documentSignatureSkipped = true
  - documentSignatureSkippedReason = "Technical Issues"

#### UpdatePASDocumentsStatusSubmitted

During this state, Onboarding makes a pass-through request to Plan Setup API (to PAS) to update the document status in PAS to SignaturePending

### Failure States

#### ComplianceCheckFailed

Compliance check against plan data written to PAS failed

#### GeneratePASDocumentsFailed

PAS encountered an error when trying to generate plan documents

#### VerifyPlanDocumentsStatusTimedOut

PAS documents were not generated within the expected time period (~5 minutes)

#### ProcessPASDocumentsDataFailed

At least one document we expected to be in the package from PAS was missing and the entire package was rejected
